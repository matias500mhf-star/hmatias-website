# HMATIAS — Design direction preview

This directory is an isolated visual proposal. It is not the production website and is intentionally marked \`noindex,nofollow\`.

## Preview routes

- \`index.html\` — homepage direction
- \`facilities.html\` — internal service-page direction

## Visual direction

**Corporate Premium / Industrial Editorial**

- Preserve the established HMATIAS navy/blue identity, while using a warmer neutral canvas and a restrained light-blue accent.
- Use a confident editorial typographic hierarchy, disciplined spacing, concise copy and strong image crops.
- Use real assets already present in the HMATIAS repository; do not introduce synthetic or stock construction photography.
- Make each service page follow the same header, navigation, breadcrumb, hero, evidence, scope and CTA framework.
- Make navigation and page structure work on desktop and mobile; keep transitions restrained and honor reduced-motion preferences.
- Keep the homepage approved in production untouched. This proposal exists only in \`design-lab/\`.

## Benchmark references and what we are learning

1. [DPR Construction](https://www.dpr.com/) — clear top-level information architecture separating company, how it builds, what it builds, news and contact. Its [project finder](https://www.dpr.com/projects) offers project-type and location filters. For HMATIAS: use a structured navigation and a portfolio that can grow into a useful filterable archive, without copying DPR's wording or visual identity.
2. [Bechtel](https://www.bechtel.com/) — combines project storytelling, markets, regions, services and people into a coherent corporate narrative. For HMATIAS: connect capabilities to concrete evidence and explain the role of the company in the delivery chain.
3. [ODS Engineering website redesign](https://vegaawards.com/winner-info.php?id=48845) — the 2025 Vega Awards case describes a geometry-led, technically confident, clean and intuitive design for a structural-steel engineering firm. For HMATIAS: use confident geometry and typography, with real project images as proof.
4. [Exigent Mechanical redesign](https://gallery.gdusa.com/project/exigent-website-redesign) — the 2025 GDUSA case emphasizes strong visuals, intuitive navigation, clear messaging and brand consistency after several acquisitions. For HMATIAS: establish one consistent digital system across four service areas.
5. [IVY Engineering Group redesign](https://longsquarestudio.ca/projects/ivy-engineering-website-redesign/) — a 2025 agency case describes a structured responsive site built around credibility, expertise and project presentation. For HMATIAS: align the project portfolio and service architecture across screen sizes.

## Important implementation boundaries

- No production files are changed by this prototype.
- No API keys, SMTP credentials, CAPTCHA secrets or server-side components are included.
- The existing GitHub Pages deployment remains the production host.
- Any production redesign requires explicit approval after visual review.
- Before reusing any project photo in a public case study, verify that its provenance and publication permission are documented.
