# Source AO — Product Definition

## Positioning

Source AO is not a directory and not a generic search engine.

It is an **Angola-first procurement intelligence and execution tool** designed to turn an incomplete customer requirement into an actionable sourcing path:

**Need → interpret → expand terminology → find likely suppliers → verify exact product → confirm stock/price/lead time → prepare RFQ/quote.**

## Non-negotiable product rule

A Source AO search is not successful because it returned links.

It is successful only when it improves the user's ability to buy or quote the requested item.

## Distinct capabilities

1. Understand local and technical naming differences in Portuguese and English.
2. Extract dimensions, quantities and urgency from informal requests.
3. Search the verified Source AO index first.
4. Surface **potential suppliers** when the exact product is not yet confirmed, clearly labelled as unconfirmed.
5. Separate supplier capability from exact-product availability.
6. Require traceable confirmation before claiming stock, price, delivery or commercial availability.
7. Preserve useful results so the same difficult product is faster to source next time.
8. Prioritise Angola, then regional/import fallback only when local sourcing is exhausted.

## Commercial acceptance gate

Source AO must demonstrate useful handling of both real lost-client cases before production launch:

### Case A — Formaldehyde
Input examples:
- formol 37% 1L
- formaldeído 30-35%
- formalin
- CAS 50-00-0

Expected:
- same chemical family;
- exact public-source product evidence when available;
- likely Angola chemical/laboratory suppliers;
- no stock claim without current confirmation.

### Case B — PP strapping
Input examples:
- cinta PP 9mm
- fita de arquear 9 mm
- polypropylene strapping 9mm
- PP strap

Expected:
- same packaging-strapping family;
- 9 mm retained;
- Angola packaging/industrial suppliers surfaced as candidates;
- exact product status remains unconfirmed until supplier confirmation.

## Launch criterion

Do not promote Source AO as a finished commercial tool until staging proves:
- the two acceptance cases above return useful local options;
- D1 contains the same curated catalog/evidence as the frontend;
- supplier candidates are visibly distinct from verified exact matches;
- no fabricated stock, price or delivery claim is possible.
