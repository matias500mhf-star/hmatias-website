KARTA Privacy Policy

KARTA Identity Wallet is a digital product of HMATIAS – Prestação de Serviços SU, LDA. It is designed to work local-first and does not replace official documents issued by public authorities.

1. Data stored locally

Identity profile information, local credentials, documents, images, PDFs, biometric preference, security metadata and information required for PIN verification are stored in the application's private device storage. Vault files are encrypted before storage.

2. PIN and biometrics

KARTA does not store the wallet PIN in plaintext. Verification uses a cryptographic derived verifier with attempt controls. Biometrics are verified by the operating system; KARTA does not receive or store fingerprint templates, face templates or other raw biometric characteristics.

3. Camera, files, QR and sharing

Camera, gallery and file selection are used only when the user chooses to capture, import, scan a QR code or select a document. Sharing/export occurs only after a user action through the Android system chooser. The selected destination's privacy practices apply after a copy is shared.

4. Encrypted backups

Local backups are encrypted on the device using the backup password chosen by the user. The backup password is not embedded in the backup file.

5. Optional online account and backup

When the online service is configured and the user chooses to use it, KARTA may process the account email address, a secure password hash, authentication sessions, technical backup metadata and the encrypted backup envelope uploaded by the user. The server validates structure and integrity but does not receive the backup password needed to decrypt the content.

6. Advertising and analytics

The current KARTA mobile application does not integrate advertising, advertising identifiers or a behavioural analytics SDK. The HMATIAS website is separate from the app and is subject to the website privacy policy and consent controls.

7. Retention and deletion

Local data remains on the device until removed by the user, the delete-wallet function or app uninstallation, subject to Android behaviour. When an online account is available, the app provides controls to delete the online backup and delete the account; deleting the account removes associated records held by the service.

8. Security

KARTA uses application-private storage, secure system storage, authenticated encryption for vault files, session locking, attempt controls and HTTPS for online communication. No system can guarantee absolute security; users should keep devices updated and protect the wallet PIN and backup password.

9. Contact
